An MP3 Player powered by an ESP32, with both bluetooth and a speaker output

Features:
- Seeed studio ESP32-S3 plus for the MCU and battery charging circuit
- A 2.8in ili9341 tft color screen
- MAX17048G+T10 for battery level checking
- a rotary encoder for input, and a vol up and vol down button
- MAX98357A + 8ohm 3W speakers for use w/o bluetooth headphones/speakers
- Any single cell LiPo works, im probably going to use a 2000mAh or 3000mAh battery
